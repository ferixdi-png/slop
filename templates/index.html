ЛОГИКА

Один сервис на весь курс

Радар ищет короткие российские AI-комедийные Reels за последние 7 дней. Сначала остаются ролики строго до 10 секунд, затем они ранжируются по Viral Score 2.0 и проходят дополнительную проверку по самому видео.

Рейтинг дополнен человеческими статусами: S — срочно брать в работу, A — сильный кандидат, B — можно тестировать, C — низкий приоритет. У каждого статуса есть объяснение: скорость, аномалия автора, свежесть и достигнутые просмотры.

Для авторов, которые уже попали в наблюдение, система собирает историю просмотров. Поэтому она может отличать просто крупный ролик от аномалии: например, когда автор обычно получает 35 тысяч просмотров, а новый Reel получает 1.2 миллиона.

TOP-30 анализируется целиком: система показывает текущие повторяющиеся персонажи, локации, типы хуков, конфликты и комедийные механики. Это позволяет видеть не отдельные ролики, а текущую мету.

Из радара можно сразу открыть подходящий ролик на разбор. Исходник определяет происходящее, русскую речь и фактическую длительность. Если исходник 7.60 секунды, в Block 3 жёстко записывается 7.60 секунды — без растягивания до 10.

Block 3 содержит отдельные locks для длительности, continuity персонажей, объектов, speaker/lip-sync, поведения тела и рук, окружения, движения, камеры и запрещённых искусственных визуальных признаков. Визуальный слой всегда переводится в максимально реалистичный live-action — как настоящее случайное видео из галереи смартфона.

Для запуска нужны только два API-ключа Google AI Studio для анализа видео и Apify для поиска Reels. Отдельный ключ радара и настройки партнёрки не нужны. Генерация отдельно от панели Сервис не запускает видеогенерацию и не расходует видеокредиты. Он анализирует исходник и собирает готовый Frame 0 + production prompt, который пользователь переносит в свой генератор. Важно для Render Free Локальная SQLite база подходит для теста, но бесплатный веб сервис имеет временную файловую систему. Для постоянной библиотеки следующим этапом подключаем PostgreSQL или persistent disk.
