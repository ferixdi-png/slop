# ФАБРИКА СЛОПА

Личная русскоязычная панель для поиска свежих коротких AI-комедийных Reels, отбора по скорости набора просмотров и сборки производственного пакета 0–5 по исходному видео.

## Что уже реализовано

- загрузка короткого видео и анализ всего визуального и аудиоряда;
- глобальный режим максимального фотореализма независимо от визуального качества исходника;
- фиксированный производственный пакет из 6 блоков:
  - Блок 0 — режиссёрское решение;
  - Блок 1 — подробный Frame 0 prompt;
  - Блок 2 — карта проверки первого кадра;
  - Блок 3 — JSON для видео с Literal Speaker Binding и First/Then/Finally;
  - Блок 4 — аудио без тире и знаков препинания;
  - Блок 5 — публикация;
- отдельная личная библиотека готовых разборов;
- радар Instagram Reels за последние 7 дней;
- фильтр длительности до 10 секунд;
- сортировка по `просмотры / часы с публикации`;
- отдельные источники Apify для поисковых запросов и хештегов;
- второй AI-фильтр смотрит само видео и оставляет только русские AI-комедийные сценки;
- автоматическое накопление авторов подходящих роликов;
- на следующих запусках радар отдельно проверяет уже найденных авторов и объединяет их свежие ролики с результатами поисковых запросов и хештегов;
- кнопка «РАЗОБРАТЬ 1:1» прямо из радара, если Apify вернул прямой videoUrl;
- подготовка для Render через `render.yaml`.

## Поисковые запросы радара

`нейроюмор`, `ии юмор`, `нейросеть прикол`, `нейросеть юмор`, `AI прикол`, `AI юмор`, `AI бабушка`, `нейросеть бабушка`, `AI деревня`, `нейросеть деревня`, `AI семья`, `AI муж жена`, `AI дед`, `AI животные юмор`, `AI скетч`.

Хештеги: `#нейроюмор`, `#ииюмор`, `#аиюмор`, `#нейросеть`, `#нейросети`, `#aivideo`, `#бабушка`, `#деревня`, `#приколы`, `#юмор`.

## Какие секреты нужны

### 1. `GEMINI_API_KEY`

Нужен серверу для анализа загруженного видео и дешёвого AI-фильтра кандидатов радара.

Рекомендуемые настройки по умолчанию:

- точный основной разбор: `ANALYSIS_MODEL=gemini-3.5-flash`;
- массовая фильтрация радара: `RADAR_MODEL=gemini-3.1-flash-lite`.

Модели меняются через переменные окружения без изменения кода.

### 2. `APIFY_API_TOKEN`

Нужен только для автоматического радара Instagram.

Используются официальные actors:

- `apify/instagram-search-scraper` — поиск Popular Reels по ключевым запросам;
- `apify/instagram-hashtag-scraper` — отдельный сбор Reels по хештегам;
- `apify/instagram-profile-scraper` — повторный мониторинг уже найденных авторов.

### Не нужны

- логин или пароль Instagram;
- ключ генератора видео, если пользователь генерирует вручную в своём аккаунте;
- ключ генератора изображений, если Frame 0 создаётся вручную по готовому prompt;
- отдельная база данных для первого MVP.

## Запуск локально

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS Linux
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
python app.py
```

Открыть `http://localhost:5000`.

## Радар вручную

Можно выполнить напрямую:

```bash
python radar_worker.py
```

Или вызвать серверный endpoint:

```bash
curl -X POST http://localhost:5000/api/radar/sync \
  -H "X-Radar-Key: ЗНАЧЕНИЕ_RADAR_SYNC_KEY"
```

Для Render удобнее запускать `python radar_worker.py` по расписанию отдельным Cron Job. Сам интерфейс всегда показывает скользящий TOP за последние 7 дней.

## Деплой на Render

1. Создать Web Service из GitHub-репозитория или использовать Blueprint из `render.yaml`.
2. Добавить секреты `GEMINI_API_KEY` и `APIFY_API_TOKEN`.
3. Для первого теста достаточно SQLite.
4. Если база должна переживать перезапуски/редеплои, подключить Persistent Disk и поставить `DB_PATH=/var/data/slop.db`, либо заменить SQLite на PostgreSQL.
5. Для автоматического обновления радара создать Render Cron Job с командой `python radar_worker.py`.

## Важная логика стоимости

Панель сама видео не генерирует. Она оплачивает только анализ входного ролика через API. Финальный production prompt пользователь переносит в свой видеогенератор отдельно. Поэтому видеокредиты пользователя не тратятся во время анализа на нашем сервере.

## Ограничение точного режима

В интерфейсе есть подтверждение прав на точное использование исходной речи и узнаваемых элементов. При подтверждении система старается сохранить речь и постановку максимально буквально. Без подтверждения система сохраняет структуру, длительность, смысл и механику, но не должна имитировать узнаваемую личность реального человека или длинные уникальные формулировки.
