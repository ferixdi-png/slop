# ФАБРИКА СЛОПА

Русскоязычная личная панель AI-креатора для поиска свежих коротких AI-комедийных Reels, отбора реально аномальных залётов и сборки производственного пакета 0–5 по выбранному исходному видео.

## Что делает сервис

### 1. Радар недели

Сервис ищет российские AI-комедийные Reels по набору ключевых запросов и хештегов, а также повторно мониторит уже найденных сильных авторов.

Жёсткий первичный фильтр:

- последние 7 дней;
- длительность до 10 секунд;
- Instagram Reels;
- после числового отбора само видео дополнительно проверяется моделью;
- остаются русские AI-комедийные сценки, бытовой абсурд и короткие приколы;
- отбрасываются обучалки, обзоры AI-сервисов, talking head и обычные текстовые мемы.

### 2. Viral Score 2.0

Радар больше не сортирует ролики только по общим просмотрам или просмотрам в час.

Итоговый score 0–100 учитывает:

- 35% — скорость набора просмотров;
- 25% — аномалию относительно обычных просмотров автора;
- 15% — просмотры относительно размера аккаунта;
- 15% — лайки и комментарии относительно просмотров;
- 10% — свежесть публикации.

Для новых авторов, по которым истории ещё мало, сервис не выдумывает базовую цифру. В интерфейсе показывается «база автора собирается».

### 3. Аномалия автора

Для уже отслеживаемых креаторов система берёт свежие Reels и считает медиану просмотров. Поэтому карточка может показывать:

```text
обычно автор: 35 тыс
этот ролик: 1.2 млн
аномалия: ×34
```

Это позволяет заметить ролик маленького автора, который реально выстрелил, даже если абсолютные просмотры ниже, чем у крупного аккаунта.

### 4. Мета недели

После полного обновления радар берёт текущий TOP и анализирует его целиком.

Панель показывает:

- повторяющиеся типы персонажей;
- повторяющиеся локации;
- повторяющиеся хуки;
- повторяющиеся конфликты и бытовые ситуации;
- кластеры форматов;
- сколько роликов начинается с вопросительного хука;
- среднюю длительность TOP;
- короткие выводы «что сейчас брать в работу».

Пример:

```text
11 роликов — пожилые персонажи
8 — деревня
7 — конфликт мужчина/женщина
14 — вопрос в начале
средняя длина — 7.6 сек
```

### 5. Разбор выбранного ролика

Из радара можно нажать «РАЗОБРАТЬ 1:1» либо загрузить видео вручную.

На выходе фиксированные 6 блоков:

0. Режиссёрское решение.
1. Frame 0 prompt.
2. Карта проверки первого кадра.
3. JSON-промпт для видео.
4. Аудио, произношение и интонации.
5. Публикация.

Речь привязывается напрямую к визуальному описанию говорящего. Видеотаймлайн строится через First / Then / Finally без секундных таймкодов. Русский текст речи очищается от лишней пунктуации.

## Absolute Smartphone Realism Override

Это глобальное правило выше стилистики исходника.

Исходный ролик определяет ЧТО происходит:

- персонажей и их роли;
- композицию;
- позы;
- действия;
- предметы;
- порядок событий;
- реплики;
- реакции;
- темп;
- комедийный payoff.

Но исходник НЕ определяет искусственный стиль рендера.

Даже если исходник — мультфильм, CGI, 3D, пластиковый AI-ролик или сильно стилизованная генерация, конечный prompt переводит всё в физически правдоподобный live-action мир.

Обязательные признаки финального результата:

- обычная вертикальная съёмка на флагманский смартфон 2024–2026;
- реальные поры и микротекстура кожи;
- естественная асимметрия лица и поведения;
- отдельные волосы и flyaways;
- анатомически нормальные руки;
- настоящая толщина, складки и натяжение ткани;
- реальные материалы и контактные тени;
- естественный свет из окружения;
- автоэкспозиция и автофокус;
- лёгкая ручная микротряска и дрейф кадра;
- небольшие бытовые несовершенства;
- без beauty filter;
- без пластиковой кожи;
- без CGI look;
- без fake HDR;
- без студийного glamour света;
- без искусственного кинематографического боке.

## Какие ключи нужны

Для запуска нужны только два внешних ключа:

```text
GEMINI_API_KEY=...
APIFY_API_TOKEN=...
```

Больше пользователю ничего придумывать и настраивать не нужно.

`SECRET_KEY` на Render создаётся автоматически. Модели и Apify actors уже имеют значения по умолчанию.

## Запуск локально

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
python app.py
```

Открыть:

```text
http://localhost:5000
```

## Деплой на Render

1. Создать Web Service из этого GitHub-репозитория или использовать `render.yaml`.
2. В Environment добавить `GEMINI_API_KEY`.
3. Добавить `APIFY_API_TOKEN`.
4. Запустить deploy.

Всё остальное уже задано в проекте.

### Защита от случайных дорогих запусков

Отдельного `RADAR_SYNC_KEY` больше нет.

Вместо этого сервер сам ограничивает полный ручной запуск радара: после успешного старта новый полный поиск нельзя мгновенно запустить повторно. Это защищает Apify-бюджет и не требует от ученика ещё одного пароля.

## База данных

Для первого MVP используется SQLite.

На бесплатном Render локальная файловая система временная, поэтому для постоянной библиотеки и накопления истории авторов следующим этапом лучше подключить PostgreSQL или persistent disk.

Накопление истории особенно важно для функции «аномалия автора»: чем больше свежих роликов автора прошло через мониторинг, тем надёжнее его базовая медиана просмотров.

## Логика стоимости

Панель сама не генерирует видео.

Она тратит API только на:

- поиск Reels;
- анализ кандидатов радара;
- анализ выбранного видео;
- короткий агрегированный анализ текущего TOP для «Меты недели».

Финальный production prompt пользователь переносит в видеогенератор отдельно.
